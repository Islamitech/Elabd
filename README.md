# اكزوتيك العبد للرخام والجرانيت | Exotic El-Abd Marble 🏛️

> **فخامة الطبيعة، إبداع مصري لا يتناهى**  
> *Nature's Luxury, Endless Egyptian Creativity*

الموقع التعريفي والكتالوج الرقمي الفاخر لشركة **اكزوتيك العبد للرخام والجرانيت** (Exotic El-Abd Marble)، إحدى كبرى الشركات المصرية الرائدة في استيراد وتصنيع أرقى أحجار الرخام والجرانيت والأونيكس الطبيعي.

---

## ✨ المميزات الرئيسية (Key Features)

- **هوية بصرية ملكية**: لوحة ألوان فاخرة تجمع بين الأبيض الرخامي، الذهبي الملكي، والفحمي الداكن.
- **دعم ثنائي اللغة (Bilingual Support)**: تبديل فوري وسلس بين اللغة **العربية (RTL)** واللغة **الإنجليزية (LTR)**.
- **شاشة بداية سينمائية (100vh Hero)**: معرض شرائح متحرك مع إحصائيات معتمدة عن خبرة الشركة ومشاريعها.
- **كتالوج منتجات تفاعلي (Interactive Catalog)**: تصفح وفلترة الرخام المصري الأصيل، الرخام المستورد، الجرانيت، والأونيكس المضيء، مع نافذة فحص المواصفات وتطابق العروق (Bookmatch).
- **معرض المشاريع الفاخرة (Featured Projects)**: استعراض أبرز المشاريع المنفذة عبر مصر في التجمع الخامس، الشيخ زايد، العاصمة الإدارية، الساحل الشمالي، والجونة.
- **حاسبة ونظام طلب عروض الأسعار (Quote Calculator)**: نافذة مخصصة لحساب المساحة ونوع الحجر مع إمكانية الإرسال المباشر عبر واتساب.
- **قسم الاتصال والمقر المصري (Contact & Location)**: أرقام الهواتف الرسمية في مصر، نموذج استفسارات سريع، وخريطة مدمجة للمصانع ومقر شق التعبان والمعارض.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Cairo, Tajawal, Playfair Display, Montserrat

---

## 🚀 التشغيل محلياً (Run Locally)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
